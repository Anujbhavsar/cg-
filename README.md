## ⚙️ Getting started

### Requirements

The practicals use Python, [NumPy](https://numpy.org/), and [Matplotlib](https://matplotlib.org/).

Install the libraries with:

```bash
python -m pip install numpy matplotlib
```

### Run a practical

Clone or download this repository, open a terminal in its folder, and run any practical. For example:

```bash
python Practical_1_DDA_Line.py
```

Replace the filename with the linked `.py` file for the practical you want to try. Programs that create plots or animations open a Matplotlib window.
